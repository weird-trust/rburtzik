# Robert Burtzik — Portfolio Site

Personal portfolio site for Robert Burtzik (interface designer and creative developer). Built with SvelteKit and Vite, featuring interactive project navigation and a custom p5 cursor animation.

## Highlights
- Project overview with hover-driven details and media previews.
- Interactive cursor animation rendered with p5.
- Responsive layout optimized for desktop and mobile.
- Deployed on Vercel.

## Tech Stack
- SvelteKit
- Vite
- TypeScript
- p5

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```

## Deploy
This project is deployed on Vercel. Production builds are generated via `npm run build`.
